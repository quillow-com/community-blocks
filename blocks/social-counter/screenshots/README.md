# Screenshot provenance

These are separate Chromium captures of the actual block at 1× pixel density,
taken on 2026-11-10:

| File         | Layout | Image dimensions |
| ------------ | ------ | ---------------- |
| `small.png`  | Small  | 156 × 156 pixels |
| `medium.png` | Medium | 336 × 156 pixels |
| `large.png`  | Large  | 336 × 336 pixels |

The packaged HTML/CSS/JS was served over local HTTP and opened standalone in a
viewport of exactly each layout size, light theme, with no host connection. The
blocks therefore show their built-in default content. The images are not resized
versions of one capture. They are not captures of the Quillow application.

These catalog assets stay outside `package/` and never enter the upload ZIP.
