# Community blocks

Each immediate child directory is one catalog entry:

```text
blocks/<slug>/
├── metadata.json
├── version.txt         # 0.0.0 until release-please prepares the first release
├── CHANGELOG.md        # Generated by release-please, outside the ZIP
├── README.md
├── screenshots/        # Three required screenshots, outside the ZIP
└── package/            # The entire ZIP input
    ├── manifest.json
    ├── index.html
    └── ...
```

Start with `npm run new -- my-widget --author your-github-handle`.
Read [CONTRIBUTING.md](../CONTRIBUTING.md) before opening a PR.

Each entry needs a block name, description, author name/GitHub username, and three
real screenshots ordered small (156 × 156), medium (336 × 156), large (336 × 336)
in `metadata.screenshots`. The generator includes capture instructions, not images.

This README is not a catalog entry. Examples are intentionally kept in `examples/`.
