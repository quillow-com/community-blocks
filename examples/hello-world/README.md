# Hello world

A responsive, network-free example. It has no storage writes and no editor screen.
Its local button toggles a message; theme and layout come from the bundled SDK.

Serve `package/` over local HTTP to preview it. Check the small (156 × 156), medium
(336 × 156), and large (336 × 336) layouts before submitting a real block.

Replace this README, the manifest name, description and authorship when copying
the example. Add the three required screenshots outside `package/`, in small,
medium, large order; see [`screenshots/README.md`](screenshots/README.md). The
example intentionally includes no fake images. A generated community entry cannot
pass checks or build until real screenshots are supplied. Do not put this README
or metadata in the ZIP. The SDK's MIT notice is included in `runtime.js`.
